# pt-PT vocabulary

Load when a word is in doubt. Where pt-PT accepts two words, the first is the safer choice. When a term still is not here, check Priberam (dicionario.priberam.org) or Infopédia, which mark Brazilian uses as [Brasil], or Ciberdúvidas for usage questions.

## Words that change meaning across the Atlantic

| word | pt-PT | pt-BR |
|---|---|---|
| fato | suit | fact (pt-PT: facto) |
| apelido | surname | nickname |
| constipado | has a cold | constipated |
| propina | tuition fee | bribe |
| salvar | rescue | save a file (pt-PT: guardar) |
| perceber | understand | notice |
| camisola | jumper, sports shirt | nightdress |
| rapariga | girl (neutral) | offensive in much of Brazil; avoid if Brazilians may read |
| bicha | queue (old, regional) | slur; write *fila* |
